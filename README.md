# To do list

یک اپلیکیشن سادهٔ فهرست کارها به زبان فارسی، با رابط راست‌چین و پشتیبانی از نمایش موبایل.

**نسخهٔ آنلاین:** https://nastaranmrz.github.io/today/

## اجرا

برای دیدن اپ، فایل `index.html` را در یک مرورگر جدید باز کنید. نسخهٔ منتشرشده از GitHub Pages در لینک بالا در دسترس است. این پروژه در حال حاضر یک اپ استاتیک است و فرایند build لازم ندارد.

## امکانات

- افزودن، ویرایش، تکمیل و حذف کارها
- جست‌وجو و فیلتر کارها
- انتخاب تاریخ، ساعت یا بازهٔ زمانی و تکرار روزانه
- ذخیرهٔ کارها و تنظیمات در مرورگر همان دستگاه با `localStorage`
- حالت روشن و تاریک و رابط فارسی راست‌چین

## داده و حریم خصوصی

کارها و تنظیمات در فضای ذخیره‌سازی محلی همان مرورگر نگهداری می‌شوند؛ در نتیجه به‌طور خودکار بین دستگاه‌ها همگام نمی‌شوند. پاک‌کردن داده‌های سایت یا مرورگر می‌تواند داده‌های محلی را حذف کند.

## راهنمای تست دستی

برای سناریوهای آزمون، معیار موفقیت و وضعیت فعلی، فایل [TESTING.md](TESTING.md) را ببینید.

## توسعه و مجوز

فایل رابط و منطق فعلی اپ در `index.html` قرار دارد. هنوز مجوز استفاده و بازتوزیع کد در مخزن تعیین نشده است؛ عمومی‌بودن مخزن به‌تنهایی مجوز بازاستفاده محسوب نمی‌شود.
